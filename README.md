# Nature-s-Force
Nature's Force is a platformer game, coded with the Godot engine, where you control a cute little robot penguin with a powerful shotgun !    
The shotgun can be used as a weapon, but especially as a movement tool, allowing you burst of movements through the skies thanks to its strong recoil.    
You will have to advance through the 7 or so levels by clever use of the movement opportunities of your weapon, fight small robotic animals, and a powerful boss: Ramachnid !

## Download
Clone this repository to have access to the code. You will be able to open the project with Godot to edit it.    
For the playable version, a windows executable is available on the build folder (you can download that folder individually if you only want to play the game).    
The pck file is essential for the executable to work. The two should be in the same folder.    

## How to play
<img width="1697" height="817" alt="tuto_ntforce" src="https://github.com/user-attachments/assets/9dec5b75-08ac-4678-accf-f426f789f539" />  
    
The player character can move and jump with zqsd/wasd or the arrow keys.    
The mouse is essential, as your shotfun will align itself with the mouse pointer.    
A left click (or space bar) will fire the shotgun, and a right click the laser sword.    
The escape key makes you return to the menu, or quit the game if you're already there.
